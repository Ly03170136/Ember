# 余烬 EMBER - 末日生存局域网联机游戏

## 项目简介
俯视角2D末日生存游戏，支持最多4人局域网联机。采集资源、建造基地、抵御丧尸、活下去。

## 如何运行

### 1. 安装 Godot 4.x
- 下载地址：https://godotengine.org/download/windows/
- 下载 **Windows 标准版**（.NET 版不需要）
- 解压后双击 `Godot_v4.x-stable_win64.exe` 运行

### 2. 导入项目
- 打开 Godot，点击「导入」
- 选择项目文件夹下的 `project.godot` 文件
- 点击「导入 & 编辑」
- 按 F5 运行游戏（或点击右上角的运行按钮）

## 如何联机

### 主机（创建游戏）
1. 运行游戏，在主菜单输入玩家名字
2. 点击「创建主机」
3. 等待其他玩家加入

### 客户端（加入游戏）
1. 运行游戏，在主菜单输入玩家名字
2. 在「主机IP」处输入主机的局域网IP（如 `192.168.1.100`）
3. 点击「加入游戏」

### 查看本机IP
- 按 `Win+R`，输入 `cmd`，回车
- 输入 `ipconfig`，查看「IPv4 地址」
- 确保所有玩家在同一个WiFi/局域网下
- Windows防火墙可能会弹窗，选择「允许访问」

## 常见问题

**Q: 客户端连不上主机？**
A: 1. 确认在同一局域网 2. 检查IP是否正确 3. Windows防火墙允许Godot访问网络 4. 关闭VPN

**Q: 游戏很卡？**
A: P0版本还在优化中，丧尸数量较多时可能卡顿。后续会优化性能。

**Q: 怎么退出游戏？**
A: 按 `Alt+F4` 关闭窗口，或在Godot编辑器里按 F8 停止运行。
